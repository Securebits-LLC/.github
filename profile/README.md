08/03/2026: Trace Driven RiscV 64b OOO core model released to datacenter-processing-elements under src-sim folder. Model is capable of being parameterized/configurable for fetch_width (default=8), decode_width (default=8), int/fp/vector_rename (default=64), dispatch/issue(default=8), retire(default=8) with configurable issue queue to execution pipe mapping e.g: specific mapping of int, float/fmac, branch, vector and sys opcodes from configurable number of Issue queues to individual/specific execution units (max:10). it is possible to configure the execution latency tables for these execution units as well. It is also possible to parametrize Dcache/L1 size(max 64KB). Currently under riscv-perf repo under src-sim in datacenter elements, there are benchmarks/tests which can be simulated. Model can be simulated under three configs (Big Core, Medium and Small core where big/medium/small are parametrized for each pipe stage like fetch width, decode width...) and can generate the performance detailed telemetry for individual stages of pipeline. Model will be enhanced for custom vector ISA in near future besides scalar functionality to make it more useful for AI/ML workloads.
