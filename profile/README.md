
This site contains development work in three main repositories. In order to get a bigger picture, please visit www.securedatabits.com/about-page for mission and www.securedatabits.com/blog-page for technical objectives. Here on this site, first repository (name: Datacenter-Processing-Elements) is related to AI training and inference specific datacenter acceleration/security/reliability IP's, second repository (name: Datacenter-Processing-Elements) contains AI inference IP's specific to domain IOTs and embedded devices with focus on acceleration/security/reliability attributes and finally third repository (name: Bio-analytics) contains Small Language Model enabled Bio Analytics for genomic/drug-discovery datasets.


07/20/2026 update in Datacenter-Processing-Elements Repo: Functional and Tested updates are related to System Level Dram (DDR4 - DDR5) and HBM Memory (HBM2/3/4) architecture model with fine grain scheduling, configurable protocols/capacity/channels/dram type/HBM IO(#channels/#dimms/#dram types/HBM IO's#) variants, input stimulus generation, Performance metering (thruput, latency...) and reporting on standard workloads and custom AI/ML traffic pattern. Integration to Scalability and coherence primitives to accelerators and processing elements is in progress.


08/03/2026: Trace Driven RiscV 64b OOO core model released to src-sim folder under Datacenter-Processing-Elements Repo. Model is capable of being parameterized/configurable for fetch width/decode width/(int/fp/vector) related rename, dispatch/issue width, retire width with configurable issue queue to execution pipe mapping. Model can be simulated under three configs (Big Core, Medium and Small core where big/medium/small are parametrized for each pipe stage parameters) and can generate the performance detailed telemetry for individual stages of pipeline. Model will be enhanced for custom vector ISA in near future besides scalar functionality to make it more useful for AI/ML workloads.
